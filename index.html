        Comment ça fonctionne

        MiseEnWeb lit la structure de votre document plutôt que son apparence. Il reconnaît la sorte de document, corrige ce que Word cache, puis vous dit ce qu'il faut vérifier.

        1. Un réglage par sorte de document

          Thèse, rapport, article de revue : chaque sorte de document a ses propres réglages. MiseEnWeb choisit les bons d'après le nom du fichier, ses styles et l'ISSN de la revue.

        2. Une structure réparée

          Les titres faits à la main deviennent de vrais titres, les entêtes de tableaux sont marqués, les adresses deviennent cliquables. Votre document d'origine n'est jamais modifié.

        3. Des points à vérifier

          Images sans description, titres qui sautent un niveau, liens vagues : chaque problème est expliqué, avec la correction à faire dans Word.

        Vos documents restent chez vous

        La conversion se fait entièrement dans votre navigateur. Aucun fichier n'est envoyé à un serveur, ni aux Bibliothèques, ni à un service externe. Fermer la page efface tout.

        Questions fréquentes

        Le résultat est-il prêt à publier ?

        Presque toujours, mais il faut le vérifier. Ouvrez « Aperçu et vérification » : le plan du document et la liste des points à vérifier vous mènent directement aux endroits concernés.

        Comment publier la page dans StudiUM ou un autre site ?

        Utilisez « Copier le code », puis collez-le dans l'éditeur du site. Dans un éditeur visuel, le texte arrive mis en forme ; dans un champ de code HTML, c'est le code qui est collé.

        Puis-je installer MiseEnWeb comme une application ?

        Oui. Installée, MiseEnWeb s'ouvre dans sa propre fenêtre et fonctionne sans connexion. Avec Chrome ou Edge, vous pouvez aussi ouvrir un document Word directement avec elle : clic droit sur le fichier, puis « Ouvrir avec », puis « MiseEnWeb ».

        MiseEnWeb est installée sur cet appareil.

        • Chrome ou Edge, sous Windows, macOS, Linux ou ChromeOS : icône « Installer » au bout de la barre d'adresse, ou menu , puis « Installer MiseEnWeb ».
        • Safari sur Mac : menu « Fichier », puis « Ajouter au Dock ».
        • iPhone et iPad : bouton « Partager », puis « Sur l'écran d'accueil ».
        • Android : menu , puis « Installer l'application ».
        • Firefox n'installe pas d'application sur ordinateur : utilisez la page dans un onglet.
        Pourquoi le premier chargement prend-il quelques secondes ?

        La page télécharge le convertisseur, environ 15 Mo, pour qu'il fonctionne dans votre navigateur. Il est ensuite gardé sur votre appareil : les visites suivantes sont presque instantanées, et la page fonctionne même sans connexion.
